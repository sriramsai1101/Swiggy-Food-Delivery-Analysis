# Swiggy Food Delivery Analysis 

Exploratory Data Analysis (EDA) on Swiggy food delivery dataset using Python.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
- 1749 restaurants
- 7 columns: hotel_name, rating, time_minutes, food_type, location, offer_above, offer_percentage

## What I Did
- Loaded and explored the dataset
- Cleaned missing values and converted data types
- Analyzed ratings, delivery times, locations and food types
- Created 5 visualizations

## Charts
1. Top 10 Locations with Most Restaurants (Bar Chart)
2. Top 10 Food Types (Bar Chart)
3. Distribution of Restaurant Ratings (Histogram)
4. Delivery Time vs Rating (Scatter Plot)
5. Rating Distribution by Top 10 Locations (Box Plot)

## Key Insights
- Total restaurants analyzed: 1749
- Average rating: 4.13
- Average delivery time: 42.33 minutes
- Most popular location: Borivali
- Most popular food type: Chinese
- Highest rated restaurant: Rajus Fast Food
- Fastest delivery: 12 minutes
- Slowest delivery: 81 minutes
